# Ahamed Jobayer — Academic Portfolio

A minimal, responsive academic portfolio built with plain HTML, CSS, and JavaScript. It defaults to a white background with black text and includes a theme toggle for black background with white text. The visitor's preference is saved in their browser.

## Files

- `index.html` — the complete website
- `assets/ahamed-jobayer-cv.docx` — your CV, linked from the homepage

## Publish for free with GitHub Pages

1. Sign in to [GitHub](https://github.com/) or create a free account.
2. Create a **new public repository** named exactly `YOUR-USERNAME.github.io`, replacing `YOUR-USERNAME` with your GitHub username.
3. Upload `index.html`, the `assets` folder, and this `README.md` to the repository's root. Keep the `assets` folder structure intact.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose the `main` branch and `/(root)`, then click **Save**.
7. Wait a few minutes. Your website should appear at `https://YOUR-USERNAME.github.io/`.

You can update the website later by editing `index.html` directly on GitHub or uploading a revised file.

## Before publishing

- Review all CV details and publication titles.
- Confirm that you want your email and phone/address details to be public. This version only displays your email and city/region, not your phone number or full street address.
- The CV download is a Word document. If you prefer a PDF CV, replace it with a PDF and update the link in `index.html`.
- If you later want a custom domain, you can configure one in GitHub Pages; the GitHub address is free.
